## 碗底分析增强版 (二次迭代)
- 发现原算法缺陷：仅凭"区间低位+近期走平"会把"仍在下跌"的板块误判为碗底（如华为机器人20日跌31%仍得60分）
- 编写增强版分析 `bowl_bottom_enhanced.py`，新增3项关键判定：
  1. **双窗口趋势减速比** = 近20日跌幅 ÷ 前40日(等效20日)跌幅，越小代表跌势减速越明显（0≈已止跌）
  2. **低点抬升检测** = 近10日低点 vs 前10日低点，碗底应形成抬高的低点
  3. **二次曲线U形拟合** = 对120日收盘价拟合 ax²+bx+c，a>0(凸性)+谷点位于近期=U形
- 形态分级：🟢确认碗底(减速<0.8+抬底) / 🟡减速筑底 / 🔴下跌中继 / ⚪观望
- 重新分析结果（78个板块）：
  - 🟢 碗底确认/确认中 9个：商贸零售、REITs、水产品、一汽系、交通运输、航运概念、美容护理、家用电器、沪伦通
  - 🟡 减速筑底 7个：在线旅游、振兴东北、供应链金融、新零售、钢铁、房地产、传媒
  - 🔴 下跌中继 48个
- 生成新报告 `generate_bowl_report.py` → `sector_bowl_report.html`，含9个碗底题材120日K线缩略图
- 数据文件：`bowl_bottom_enhanced.json`
